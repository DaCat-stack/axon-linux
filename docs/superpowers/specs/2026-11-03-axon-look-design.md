# AXON Linux — внешний вид и установка

Дата: 2026-11-03. Статус: черновик, ждёт одобрения владельца.

## Зачем
AXON Linux — личный игровой дистрибутив владельца (Arch + KDE Plasma 6). Сейчас ISO
загружается в стандартный вид Arch/KDE. Нужно, чтобы с первой секунды было видно,
что это **AXON**: своя загрузка, своё окно входа, свой рабочий стол, простая
установка. Ориентиры владельца: «что-то похожее на мак и на Ubuntu».

## Цели
1. Экран загрузки с анимацией лого AXON.
2. Своё окно входа (вариант C, «гибрид»).
3. Рабочий стол: три готовых пресета, выбор при первом запуске, по умолчанию A.
4. Графическая установка в стиле AXON, умеющая ставить рядом с Windows, вместо неё и вручную.

## Не цели
- Своя оболочка рабочего стола с нуля (берём KDE Plasma и настраиваем).
- Своя тема иконок (берём готовую, см. «Решения сборщика»).
- Ограничивать кастомизацию: всё, что задаём, — только стартовые настройки,
  владелец потом меняет что угодно через KDE.

## Анти-цели (провал, даже если «работает»)
- Ломается после обновления KDE (сторонние виджеты, хрупкие хаки).
- Обновление AXON перезаписывает личные настройки пользователя.
- Установщик может молча снести Windows.
- Лого искажено/сплющено где-либо.

## Общие ресурсы
- Лого: `assets/axon-logo.png` (1024×1024, прозрачный фон; синий малый парус
  с градиентом бирюзовый→синий + белый большой парус). Части для анимации:
  `assets/logo-blue.png`, `assets/logo-white.png` (тот же холст 1024×1024, совмещаются один в один).
- Цвета: фон `#07090d` (загрузка), `#0a0f1c` (обои), бирюзовый `#28a8a8`, синий `#2f86f0`.
- Обои = фон окна входа: тёмно-синий, размытые бирюзовое (снизу слева) и синее
  (сверху справа) пятна, слабое фиолетовое в центре, большой белый парус в правом
  нижнем углу с прозрачностью ~5%. Рендерится в PNG 3840×2160 (и 1920×1080).
- Макеты, утверждённые владельцем, лежат в `.superpowers/brainstorm/…/content/`:
  `boot-animation-v2.html`, `login-screen.html` (вариант C), `desktop.html`, `installer.html`.

## 1. Экран загрузки (Plymouth)
Утверждено: макет `boot-animation-v2.html`, индикатор «точки».
- Чёрный фон `#07090d`, лого по центру (~190 px при 1080p), без текста.
- 0.3 с: синий парус выезжает снизу (сдвиг 40% высоты + проявление), 1 с, ease-out.
- 0.7 с: белый парус выезжает справа (сдвиг 35% ширины + проявление), 1 с.
- 1.8 с: один раз блик по белому парусу (0.9 с).
- Дальше до конца загрузки: лого «дышит» синим свечением (период 2.6 с),
  под ним три синие точки прыгают по очереди (период 1.2 с, задержка 0.2 с).
- Окно ввода пароля диска (если будет шифрование) — в том же стиле.
- Конец: плавное затухание в окно входа.
- Plymouth-тема `axon` (модуль script), включается в initramfs; параметры ядра `quiet splash`.

## 2. Окно входа (SDDM, тема `axon`, QML)
Утверждено: вариант C из `login-screen.html`.
- Фон — обои AXON с лёгким размытием.
- Верхняя панель (прозрачная): слева мини-лого + «AXON»; справа раскладка
  (RU/EN, переключается кликом), сеть, громкость, батарея (только если есть батарея).
- Центр: стеклянная карточка — часы (крупно), дата по-русски («Вторник, 3 ноября»),
  аватар (по умолчанию лого AXON на тёмном круге; если у пользователя есть
  аватар KDE — он), имя, поле пароля «Введите пароль» со стрелкой.
- Неверный пароль: поле трясётся и очищается.
- Несколько пользователей: кружки-аватары внизу карточки; один пользователь — кружков нет.
- Низ экрана: «Сон», «Перезагрузка», «Выключение».
- Гостевого входа нет.

## 3. Рабочий стол (KDE Plasma 6)
Утверждено: три пресета, выбор при первом запуске, по умолчанию A.
- **A. «Windows 11»** — плавающая панель по центру снизу: кнопка меню (лого AXON),
  закреплённые: Firefox, Файлы, Steam, Lutris, Discord, Терминал
  (Discord добавляем в пакеты, он есть в официальном репозитории — решение моё).
  Справа отдельная плавающая панель: трей + часы с датой.
- **B. «Mac»** — тонкая полупрозрачная верхняя панель (меню AXON, глобальное меню
  программы, трей, часы); снизу плавающий док по центру с увеличением иконок при наведении.
- **C. «Ubuntu»** — тёмная верхняя панель («Обзор» слева, дата/время по центру,
  трей справа); слева вертикальный док, внизу дока кнопка «Все приложения».
- Каждый пресет — Plasma Global Theme (look-and-feel) `AXON A/B/C` с раскладкой
  панелей; цветовая схема тёмная, общая для всех.
- **Окно приветствия AXON** при первом входе: «Выбери свой стиль» — три карточки
  A/B/C с превью, применяется в один клик; дальше можно открыть снова из меню.
- Обои AXON по умолчанию на рабочем столе и экране блокировки.
- Всё задаётся как значения по умолчанию системы (`/etc/xdg`, `/usr/share/plasma`),
  личные настройки в `~/.config` никогда не перезаписываются.

## 4. Установка (Calamares)
Утверждено: макет `installer.html`.
- В live-сессии — ярлык «Установить AXON» на рабочем столе.
- Шаги: Добро пожаловать (язык) → Регион (часовой пояс, раскладки us+ru Alt+Shift)
  → Диск → Пользователь → Итог → Установка (прогресс + слайды) → Готово.
- Диск: «Установить рядом с Windows» (ползунок размера) — первым и выбран по умолчанию,
  если найдена Windows; «Стереть диск»; «Вручную». На ПК владельца стоит Windows,
  решение «рядом или вместо» он примет при установке.
- Двойная загрузка: загрузчик видит Windows и показывает меню выбора системы.
- Пользователь: имя, имя компьютера, пароль ×2, галочка «входить автоматически».
- Слайды во время установки (4): «Игры из Steam», «Программы Windows»,
  «Твой стиль», «Магазин приложений» — тексты как в макете.
- Брендинг: тёмная боковая панель с лого AXON, кнопки с градиентом бирюзовый→синий.
- Установленная система получает всё то же оформление, что и live
  (Plymouth, SDDM, пресеты, обои), без live-пользователя и без sudo без пароля.

## Ограничения
- Сборка ISO только в GitHub Actions (у владельца M1 Mac); тест на реальном ПК
  (Intel + RTX 4060) с флешки через Ventoy, Secure Boot выключен.
- Пакеты — из официальных репозиториев Arch. Исключение: Calamares есть только
  в AUR, его (и наши пакеты, если будут) CI собирает сам в локальный репозиторий
  перед сборкой ISO. Всё своё (темы, приветствие) — файлами в `profile/airootfs`
  или своими пакетами в этом репозитории.
- Ничего не должно требовать сети при первом запуске.

## Решения сборщика (не согласовывались — на усмотрение)
- Тема иконок (предложение: Papirus-Dark, есть в репозиториях).
- Шрифт интерфейса (предложение: Inter или Noto Sans).

- Загрузчик установленной системы (systemd-boot или GRUB) — главное, чтобы
  двойная загрузка с Windows работала.
- Технология окна приветствия (QML/Kirigami предпочтительно, родное для KDE).
